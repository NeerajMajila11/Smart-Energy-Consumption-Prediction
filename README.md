# ⚡ Smart Energy Consumption Prediction using Machine Learning

## 📖 Project Overview

This project predicts household energy consumption using Machine Learning. Users can upload a CSV dataset through a Flask web application, and the trained Random Forest model predicts appliance energy consumption.

The application provides:
- Energy consumption prediction
- Interactive dashboard
- Prediction statistics
- Charts
- CSV download

## ▶️ Installation

Clone Repository

```bash
git clone <repository-link>
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
